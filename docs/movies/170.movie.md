> <Badge text="二元制律师制度" type="danger" />: 英国当时实行严格的律师分级制度，严格区分出庭律师（大律师，Barrister）与事务律师（Solicitor）：只有出庭律师才有资格在刑事高等法院出庭辩护，事务律师仅能负责案前接洽、取证，无权上庭；影片中韦菲爵士的身份是皇家法律顾问（QC，Queen's Counsel），即御用大律师，是出庭律师的最高等级。这套繁琐的司法规则对普通人十分晦涩，嫌疑人沃尔因此被绕晕，也让韦菲爵士产生了职业优越感。

## 有说法的导演
导演将**雪茄**作为影片前半段**节奏的带动者**：  
1. **借事务律师梅休的雪茄**：将正欲上楼的爵士吸引下来   
2. **找嫌疑人沃尔借火机**：将沃尔引入房间开始介绍案情，严峻的案情和嫌疑人完美的无辜的、心不在焉的表现激起了爵士对于该极具挑战性案件的莫大兴趣  
3. **抽雪茄的过程**：完成了对案件基本信息的了解  
4. **抽完雪茄**：进行了爵士经典的拿眼镜片反光照人测谎（嫌疑人沃尔在该项测试中表现堪称完美 正是因此爵士直到审判结尾等待陪审团出最终结果的时候才感觉到不对劲）   
5. **打开窗户倒抽屉中的烟灰**：为后来探出脑袋看见上来逮捕嫌疑人的苏格兰场总巡警做准备

> <Badge text="禁止双重危险原则" type="danger" />:普通法传统：作为英美法系发源地，英国通过判例确立 "一罪不二审" 原则，1998 年《人权法案》纳入欧洲人权公约相关条款。《欧洲人权公约》第 7 条：任何人已依一国法律及刑事程序被最后定罪或宣告无罪者，不得就同一罪名再予审判或惩罚。2003 年《刑事司法法》：对例外情形（如发现新证据证明无罪判决错误）作出严格限制，平衡程序正义与实质正义

## 座位
![](/images/WitnessfortheProsecution/座位.png)
注意到台上中间的两把高背椅是空出来的  
这是剧中取景地伦敦老贝利法庭中世纪 “城市司法权归属” 传统的延续  
哪怕现代司法体系里，主审法官已经完全掌握庭审的审判权，依然要为名义上的城市最高司法长官（伦敦市长）和市政核心官员保留席位，以此延续司法权的历史传承。  
最左侧席位：法官书记员的位置  
左二席位：主审法官的专属席位，也就是画面中主持庭审的法官的位置；  
中间核心空位（第一把空椅）：伦敦市市长的专属席位，是整排席位里礼仪等级最高的位置，这把椅子的正上方还固定着象征司法权威的正义之剑。理论上伦敦市长是城市名义上的最高司法长官，因此必须为他永久预留这个位置，哪怕他几乎从不出席普通庭审；  
市长位右侧空位（第二把空椅）：伦敦市高级市议员（Alderman）的专属席位，同样是法定预留的礼仪席位；  
最右侧席位：伦敦郡长、副郡长的位置，画面中最右侧已有一位官员就坐。  

```流程简介
# 一、庭审正式开始
- 法庭开庭，法官入席
- 书记员宣读起诉书：
  伦纳德·沃尔被控谋杀**艾米丽·弗伦奇**小姐
- 被告伦纳德·沃尔当庭表示：**不认罪**

# 二、控方举证阶段（Prosecution case）
控方律师迈尔斯先生依次出示证据和证人：

1. **警方证人**
   - 介绍案发现场：死者在家中遭重击身亡
   - 提交物证：沃尔袖口有与死者血型一致的血迹
2. **女管家珍妮特·麦肯锡（控方关键证人）**
   - 作证：案发时间听到沃尔与女主人争吵
   - 指证沃尔贪图女主人财产
   → 爵士对其进行**交叉询问**，质疑她听力差、对沃尔有偏见，大幅削弱证词可信度

3. **控方王炸证人：克里斯汀·沃尔**
   她以**控方证人**身份出庭，指证自己丈夫：
   - 称伦纳德案发当晚回家后承认杀人
   - 承认是她帮丈夫洗掉血衣、伪造不在场证明
   辩方瞬间陷入绝境。

# 三、辩方绝地反击
爵士几乎无计可施时，意外获得**克里斯汀写给情人的私密信件**，证明她在作伪证、意图陷害丈夫。
- 法庭尚未闭庭，爵士申请**重新传唤克里斯汀**
- 当庭宣读信件，揭穿她作伪证的动机
克里斯汀的证言彻底失效，控方证据链崩塌。

# 四、双方证据展示完毕，进入庭审收尾程序
## 1. 法官向陪审团作出指示
法官总结案情、说明法律原则：
- 陪审团只依据庭上证据判断
- 疑点利益归于被告
- 谋杀罪必须排除一切合理怀疑

## 2. 控方结案陈词（Closing speech for prosecution）
控方律师重申：
- 被告有谋财动机
- 时间、物证、证人指向被告
- 要求陪审团裁定**谋杀罪名成立**

## 3. 辩方结案陈词（爵士精彩演讲）
威尔弗里德爵士的结案陈词是全片名场面之一：
- 痛陈控方证据全是间接证据、充满漏洞
- 指出克里斯汀作伪证，人品卑劣不可信
- 强调被告自始至终没有任何确凿直接证据证明杀人
- 呼吁陪审团坚守正义，判被告**无罪**

# 五、陪审团裁决环节
1. **陪审团退庭评议**
   陪审团离开法庭，到合议室秘密讨论。
2. **陪审团返回法庭**
   全体起立，陪审团团长宣布裁决结果。
3. **正式裁决**
   陪审团一致裁定：
   **伦纳德·沃尔，谋杀罪名不成立，无罪释放。**

# 六、庭审正式结束
- 法官宣布庭审终结，被告当庭释放
- 众人离场，法庭解散
```
