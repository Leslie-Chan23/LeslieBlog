# Hachi: A Dog's Tale
*因为是在手机上看的，所以这篇没有配图。*  
第一次看是初中，再看并未感到惊艳  
应该也是因为我没有养过狗🥹🥹  
~~不过前一个小时观看时几乎没听见声音，声音的缺失对于其主观评分而言有点不公了~~  
感受到了一股浓浓的美式价值观的冲击  
白人老登与日本老登的交流  
文化输出了秋田犬的忠诚，美式的家庭观念      
不过狗狗还是很可爱的 男主的演出表现了他对hachi的尊重  
相处的过程中主角一家也逐渐把hachi当作了家人  
总之这电影看完没什么感触🤯
