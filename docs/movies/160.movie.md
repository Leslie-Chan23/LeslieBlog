或许办案就不应该带有主观色彩地认定某嫌疑人为凶手 应当以证据为依据  
抱着某某人就是凶手的心态办案 势必会妖魔化嫌疑人 所谓怀疑一旦产生罪名已然成立 自此嫌疑人的一切作为都是在狡辩  
刑讯逼供也正是在这样的心态下进行的 非常笃定此人是凶手 即便证据不足 我也要将你绳之以法以满我心中之正义  
某种意义上，采用刑讯逼供的刑警是一个独裁者 他拥有着暴力手段 拥有着解释权 而当独裁者犯错时 人们便开始质疑其独裁合理性（这也表现在第三位嫌疑人——一名年轻人 对刑警轻蔑的态度 “你们对嫌疑人进行刑讯逼供是连这里的小孩子都知道的事”） 这也与当时在全韩爆发的六月民主抗争遥遥呼应  
片中多次出现记者 面对新发的命案现场 记者们蜂拥而至 甚至比重案组刑警到的更早 人民意识到执法是需要监督的 片中的记者有各种破坏现场的行为 无疑令人气愤 但最缺乏对证据的尊敬的恰恰是作为刑警的宋康昊 为了快速结案 他不惜拿着嫌疑人的鞋子到现场伪造嫌疑人在场的证据 何其可悲  
事实上 片中金相庆饰演的来自首尔的探员 同样假定了第三名嫌疑人为凶手 这也导致了他后期的自责、奔溃乃至鉴定报告明晃晃地洗脱了第三名嫌疑人的嫌疑，却仍试图击毙他。

9.11回头看：
1.该案存在着许多的模仿犯，正与片头小男孩模仿宋康昊相契合。 因为拍这部电影时该案尚未破获。  
2.宋康昊最后的猛回头直视观众打破了第四面墙，与观众的直接对视或许也隐含着对真正罪犯的劝告。  

看到一个说法
